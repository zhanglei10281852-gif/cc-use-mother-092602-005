# 科学计算任务运营服务

这是一个面向科研平台、实验室和计算中心的 Python 后端，使用 FastAPI 与 SQLite 管理参数模板、计算任务提交、优先级排队、工作者领取、取消、失败重试、租约恢复、用户配额、结果版本和管理员人工干预记录。服务同时保留用户、角色、会话和审计等基础能力，所有运行数据都在单个本地数据库文件中，不需要另行部署数据库、缓存、消息队列或浏览器界面。

## 已有能力

- 参数模板：保存参数类型、必填项、数值范围、默认值、最大运行时间和最大尝试次数。
- 任务提交：根据模板校验参数，使用用户与幂等键避免重复创建，并保存项目、提交人和输入摘要。
- 排队领取：按优先级和进入队列的顺序分配任务，工作者可声明算法能力并获得有期限的租约。
- 执行回执：工作者可以续租、提交结果或报告失败；可重试错误使用确定的退避时间重新排队。
- 失败恢复：租约过期后可由恢复入口将任务重新排队，达到最大尝试次数的任务转为失败。
- 配额控制：可保存用户、角色或项目的排队数、运行数和每日提交上限；当前提交路径执行用户配额。
- 结果版本：每次成功回执保存不可变结果、指标摘要和内容摘要，任务指向当前结果版本。
- 人工干预：取消、人工重试、优先级调整和批量操作均保留操作者、原因、前后状态和批次标识。
- 卫星地面链路协调：登记链路时间片与租户配额，按消息优先级预留带宽，紧急遥测可抢占普通数据但不允许配额透支；延期与跨时间片迁移遵循明确规则，结算生成账单，每次决策保留当时的带宽快照。
- 登录与角色：基础管理模块提供管理员初始化、用户、角色、会话和细粒度权限。

## 运行环境

- Python 3.11
- SQLite 3，由 Python 标准库提供
- Linux、macOS 或 Windows

## 安装

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
```

默认数据库位于 `./data/compute-operations.db`。可以复制 `.env.example` 并通过 `TOWNSHIP_DATABASE_PATH` 指定其他本地路径。

## 数据库初始化与检查

```bash
python -m app.cli init-db
python -m app.cli check-db
```

## 启动 API

```bash
uvicorn app.main:app --host 0.0.0.0 --port 8432
```

健康检查：

```bash
curl -sS http://127.0.0.1:8432/api/system/health
```

计算任务摘要位于 `/api/compute/summary`，模板、配额、提交、领取、回执和人工操作接口统一使用 `/api/compute` 前缀。

## 卫星地面链路协调

`/api/downlink` 前缀提供多卫星回传场景下的地面链路带宽协调，全部通过本地 HTTP 接口验证：

- `POST /slices` 登记链路时间片（编码唯一、不允许重叠，登记后自动按迁移规则安置等待中的传输），`GET /slices` 查看各时间片已用与剩余带宽。
- `PUT /tenants/{tenant}/quota` 登记租户在每个时间片内可传输的数据量配额与计费单价，`GET /tenants/{tenant}` 查看配额与用量。
- `POST /reservations` 为消息预留带宽：同一租户下 `message_key` 唯一，相同消息重试返回首次决策结果（`outcome=replayed`），不会重复扣减带宽与配额；未登记配额或配额不足一律拒绝（紧急消息也不例外，防止透支）；带宽不足时普通消息自动延期等待，紧急消息（优先级 ≥ 90）按优先级从低到高抢占普通消息。
- `POST /reservations/{id}/release` 传输完成后释放带宽；`POST /reservations/{id}/preempt` 管理员显式抢占；`POST /messages/{id}/defer` 主动延期。
- `POST /migrations` 按明确规则迁移未完成传输：延期或被抢占的消息按优先级从高到低、同级按提交时间从早到晚，迁入同时满足剩余带宽与租户剩余配额的最早时间片，无法迁入的保持等待并记录原因。
- `POST /settlements` 结算已结束的时间片：仅对传输完成（已释放）的预留按 `消息体积 × 租户单价` 计费，被抢占、延期、迁移的预留不计费；片内仍占用链路的传输自动转入迁移等待；同一时间片只能结算一次，账单唯一约束保证不会重复扣减。
- 管理视图：`GET /decisions` 查看每次决策的原因与当时的带宽快照（含拒绝与被抢占原因），`GET /bills` 与 `GET /bills/summary` 查看最终账单，`GET /messages` 与 `GET /messages/{id}` 查看消息状态、预留轨迹与决策历史，`GET /summary` 查看总览。

## API 冒烟

```bash
python -m app.cli smoke
python -m app.cli compute-demo
python -m app.cli downlink-demo
```

`smoke` 在进程内检查根路径和健康接口，`compute-demo` 会创建示例参数模板、提交一个计算任务并让匹配能力的工作者领取，用于快速确认核心运营链路。`downlink-demo` 登记三个链路时间片与两个租户配额，演示普通数据预留、紧急遥测抢占、跨时间片迁移和时间片结算，可重复执行且不会产生重复扣减。

## 目录结构

```text
app/
  compute/         计算模板、配额、任务、结果版本和人工干预
  downlink/        卫星地面链路时间片、租户配额、预留、抢占、迁移与结算
  api/             用户、角色、认证、审计和系统管理接口
  core/            时钟、安全、异常和分页能力
  repositories/    通用 SQLite 查询
  seismic/         既有地震计算示例领域
  services/        身份、审计和通用后台任务服务
  cli.py           初始化、检查和冒烟入口
  database.py      SQLite 连接、事务、表结构与基础权限
tests/             核心、计算运营、地面链路协调和身份回归测试
tools/             本地维护脚本
```

## 数据一致性

SQLite 连接启用外键、WAL、busy timeout 和同步写入策略。提交、领取、回执和人工干预使用即时事务；任务领取通过条件更新避免同一条排队记录被重复领取。服务保存 UTC 时间字符串，测试可以注入固定时钟验证退避、租约到期和跨日配额。会话令牌只保存摘要，审计与人工干预记录不会写入明文密码或令牌。
